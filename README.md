# About Me Site

A beginner-friendly one-page website to introduce a new Salesforce team member.

## Files

- `index.html`: page content and section structure
- `styles.css`: visual style and mobile responsiveness
- `script.js`: small "Back to top" interaction

## Run Locally

1. Open this folder in Cursor.
2. Open `index.html` in your browser.
3. Update placeholder text:
   - `Your Name`
   - `your.name@example.com`
   - `@yourname`
   - `linkedin.com/in/yourname`

## Demo Script (2-3 Minutes)
